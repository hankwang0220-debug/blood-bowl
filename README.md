# 血腥橄欖球（Blood Bowl）網頁版

**▶ 線上直接玩：https://hankwang0220-debug.github.io/blood-bowl/**

規則與資料依據 **Blood Bowl 2025 版（第三版）**，以 [bloodbowlbase.ru](https://bloodbowlbase.ru/bb2025/) 整理的內容為準。

## 怎麼開始
用上面的網址就能在瀏覽器裡玩，不需要安裝任何東西。

也可以下載這個倉庫，直接用瀏覽器打開 `index.html`。

如果瀏覽器擋住本機檔案，可以改用內附的小型伺服器：
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
然後打開 http://localhost:8123/

## 玩法
1. 在選單為主隊、客隊選擇球隊（依等級分組），再調整陣容：預算 1,000k，11–16 人，可以加購隊伍重擲、隊醫、啦啦隊、助理教練，以及最多 2 組明星球員。
2. 每隊可以選「玩家操作」或「電腦 AI」：兩邊都選玩家就是同一台電腦對戰，兩邊都選電腦則是電腦對電腦。
3. 比賽中：
   - 點選己方球員 → 選擇行動（移動、阻擋、閃擊、保球、傳球、手遞、犯規、投擲隊友，以及刺擊、電鋸、噴吐、噴火、催眠凝視、鏈球等特殊行動）。
   - 也可以直接點亮起的格子移動，或點相鄰的對手阻擋。
   - 格子顏色代表成功率：白色＝安全，黃色/紅色＝需要閃避或衝刺；顏色較淡的格子要衝刺。
   - 可以跳過倒地的球員（有飛躍或彈簧高蹺的球員可以跳過任何格子）：行動中按「跳躍」。
   - 滑鼠移到球員或技能上可以看說明；淡色、有虛線底線的技能代表尚未實作。
   - 右鍵：取消選擇（布陣時則是把球員移回替補席）。快捷鍵 `E` 結束目前球員的行動。

## 已實作的 2025 版規則
- 布陣規則（含必須派上隊長、蜂擁而至）、開球（開球手可改擲 D3）、2025 版開球事件表（衝鋒、可疑點心、觀眾歡呼加協助、精彩指導的推進重擲等）、天氣、球迷人數
- 移動、閃避、衝刺、跳過倒地球員、飛躍、彈簧高蹺、撿球、**保球行動**、站起來（MA 2 以下要擲骰）
- **分心（Distracted）**狀態：木頭腦袋、超級笨蛋、催眠凝視等都會讓球員分心
- 阻擋：協助（護衛、防守專家、挖眼）、骰數、五種結果、推擠（連鎖推擠、推出場外會失誤）、跟進（擋開、挑釁、狂暴）
- 傳球：精準／不準（偏移 3 次）／失手、沿實際落點路線攔截、接球修正（彈跳與界外球 -1）、手遞、觀眾丟回場內（含角落）
- 投擲隊友 2025 版：完美投擲也會偏移（正中紅心除外）、普通投擲落地 -1、失手會彈開、撞到人會兩敗俱傷、永遠很餓
- 護甲、傷害、2025 版傷亡表（1–8 輕傷）、隊醫、再生、KO 回復、腐朽
- 犯規、爭辯判決（Argue the Call）、賄賂、秘密武器、賄賂與腐敗
- **隊伍重擲每回合不限次數**、獨行者（X+）、職業球員、隊長（擲 6 不消耗重擲）、領袖、技能重擲
- **拖延（Stalling）**：可以不擲骰達陣卻不達陣，觀眾會丟東西
- 對手回合中被推進達陣區得分時，得分隊要跳過下一回合
- 鏈球 2025 版：只能朝四個正方向、可以衝刺、撞到倒地球員會推開並擲護甲
- 92 種技能與特性，詳見遊戲內說明

## 簡化的地方
- 傳球距離用直線距離近似，而不是官方的距離尺。
- 閃擊不用事先宣告目標。
- 野性難馴失控打完隊友後，仍然可以繼續行動。
- 嗜血失敗時，行動結束時會自動咬身旁的血奴；不能改宣告成移動。
- 明星球員雙人組算作 1 組。

## 電腦 AI 會做什麼
- 撿球（附近沒有對手時改用保球行動）、保護持球者推進、達陣，或手遞給能達陣的隊友
- 傳球：傳給能跑進達陣區的隊友，或把球傳給前場沒人盯的接球手；會估算傳球、接球和被攔截的機率
- 接球手會跑到持球者前方的空位接應
- 投擲隊友：把持球的小個子丟向達陣區、丟去撿球、丟到對方持球者旁邊纏住他，或丟到前場接應
- 彈簧跳躍與飛躍：跳過人牆、跳離盯防、跳去撿球或達陣
- 刺擊、電鋸、噴吐、噴火
- 閃擊對方持球者、挑勝算高的阻擋、走位、犯規、放鏈球

## 測試
`tests/sim.js` 讓電腦對電腦連續打很多場，檢查有沒有錯誤並統計各種行動的次數。用法寫在檔案開頭。

## 程式結構
```
index.html            頁面
css/style.css         樣式
js/engine/data.js     球隊、球員、技能、明星球員資料（2025 版）
js/engine/engine.js   規則引擎（純邏輯，不碰畫面）
js/ai.js              電腦 AI
js/ui/render.js       Canvas 球場繪製
js/ui/app.js          選單、操作介面
tests/sim.js          電腦對電腦壓力測試
serve.ps1             開發用的小型伺服器
```

### 規則引擎的設計（為之後架伺服器準備）
- 整場比賽是一個 generator。需要教練做決定時，引擎會送出一個 prompt（例如 `{type:'blockDice', team:0, dice:[...]}`），前端或 AI 用 `game.act(answer)` 回答。
- 亂數由種子決定，所以「種子 + 所有回答」可以完整重播一場比賽（`game.history`）。
- 引擎不依賴瀏覽器，可以直接在 Node.js 載入（`require('./js/engine/data.js'); require('./js/engine/engine.js')` 之後使用 `globalThis.BB.Game`）。
- 架線上對戰時，伺服器保有權威的 `Game` 物件，只把對應隊伍的 prompt 送給該玩家，收到回答後驗證、執行並廣播新狀態。玩家無法自己擲骰，所以不能作弊。
