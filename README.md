# 血腥橄欖球（Blood Bowl）網頁版

**▶ 線上直接玩：https://hankwang0220-debug.github.io/blood-bowl/**

## 怎麼開始
用上面的網址就能在瀏覽器裡玩，不需要安裝任何東西。

也可以下載這個倉庫，直接用瀏覽器打開 `index.html`。

如果瀏覽器擋住本機檔案，可以改用內附的小型伺服器：
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
然後打開 http://localhost:8123/

## 玩法
1. 在選單為主隊、客隊選擇種族，再調整陣容（預算 1,000k，11–16 人）。
2. 每隊可以選「玩家操作」或「電腦 AI」：兩邊都選玩家就是同一台電腦對戰，兩邊都選電腦則是電腦對電腦。
3. 比賽中：
   - 點選己方球員 → 選擇行動（移動、阻擋、閃擊、傳球、手遞、犯規、投擲隊友）。
   - 也可以直接點亮起的格子移動，或點相鄰的對手阻擋。
   - 格子顏色代表成功率：白色＝安全，黃色/紅色＝需要閃避或衝刺；顏色較淡的格子要衝刺。
   - 滑鼠移到球員上可以查看能力值和技能說明。
   - 右鍵：取消選擇（布陣時則是把球員移回替補席）。快捷鍵 `E` 結束目前球員的行動。

## 球隊
人類、獸人、夜地精、鼠人、高等精靈、矮人。

高等精靈的資料取自使用者提供的球隊表（HighElf.pdf），包含專屬技能破雲高傳、安全傳球、我的球，以及穩健步伐（表上有說明，但目前沒有任何位置初始就有）。明星球員 **Ripper Bolgrot** 和 **Fungus the Loon** 可以加入夜地精和獸人隊。

> 2026/10/12 的 Warhammer Community 文章只公布了兩人的專屬技能（「會思考的巨魔」和「旋轉托缽僧」）。能力值、身價和其他技能暫時沿用 Blood Bowl 2020 版的資料，官方卡片公布後可以在 `js/engine/data.js` 修改。

## 已實作的規則
- 布陣規則（爭球線、邊路人數）、開球偏移、完整的 2D6 開球事件表、天氣
- 移動、閃避、衝刺（Rush）、撿球、站起來
- 阻擋：協助、骰數、五種結果、推擠（含連鎖推擠、推出場外）、跟進、狂暴
- 傳球（四種距離）、攔截、不準/嚴重偏離、失手、手遞、接球、球彈跳、觀眾丟回場內
- 護甲、傷害（含小不點傷害表）、傷亡、隊醫、再生、KO 回復
- 犯規、對子罰下場、賄賂、秘密武器
- 隊伍重擲（每回合一次）、獨行者、職業球員、技能重擲
- 投擲隊友、彈簧高蹺跳躍、鏈球（Fungus / 狂熱者）
- 約 50 種技能，見 `js/engine/data.js` 的 `BB.SKILLS`

## 電腦 AI 會做什麼
- 撿球、保護持球者推進、達陣，或手遞給能達陣的隊友
- 傳球：傳給能跑進達陣區的隊友，或把球傳給前場沒人盯的接球手；會估算傳球、接球和被攔截的機率
- 接球手（有 Catch、MA 7 以上或彈簧高蹺的球員）會跑到持球者前方的空位接應
- 投擲隊友：把持球的小個子丟向達陣區、丟去撿球、丟到對方持球者旁邊纏住他，或丟到前場接應
- 彈簧跳躍：跳過人牆、跳離盯防、跳去撿球或達陣（跳躍比閃避危險時就不跳）
- 閃擊對方持球者、挑勝算高的阻擋、走位、犯規、放鏈球

## 測試
`tests/sim.js` 讓電腦對電腦連續打很多場，檢查有沒有錯誤並統計各種行動的次數。用法寫在檔案開頭。

## 簡化的地方
- 「觀眾歡呼」和「精彩指導」都簡化成勝方多一次隊伍重擲（沒有實作 Prayers to Nuffle 表）。
- 傳球距離用直線距離近似，而不是官方的距離尺。
- 投擲隊友時，嚴重偏離的處理和不準一樣。
- 沒有實作：Always Hungry、Projectile Vomit、Animosity、Chainsaw、Bombardier、Hypnotic Gaze、Multiple Block、Diving Tackle、延長賽。
- 只有單場比賽，沒有聯賽、經驗值和球員成長。

## 程式結構
```
index.html            頁面
css/style.css         樣式
js/engine/data.js     球隊、球員、技能資料
js/engine/engine.js   規則引擎（純邏輯，不碰畫面）
js/ai.js              電腦 AI
js/ui/render.js       Canvas 球場繪製
js/ui/app.js          選單、操作介面
tests/sim.js          電腦對電腦壓力測試
serve.ps1             開發用的小型伺服器
```

### 規則引擎的設計（為之後架伺服器準備）
- 整場比賽是一個 generator。需要教練做決定時，引擎會送出一個 prompt（例如 `{type:'blockDice', team:0, dice:[...]}`），前端或 AI 用 `game.act(answer)` 回答。
- 亂數由種子決定，所以「種子 + 所有回答」可以完整重播一場比賽（`game.history`）。
- 引擎不依賴瀏覽器，可以直接在 Node.js 載入（`require('./js/engine/data.js'); require('./js/engine/engine.js')` 之後使用 `globalThis.BB.Game`）。
- 架線上對戰時，伺服器保有權威的 `Game` 物件，只把對應隊伍的 prompt 送給該玩家，收到回答後驗證、執行並廣播新狀態。玩家無法自己擲骰，所以不能作弊。
